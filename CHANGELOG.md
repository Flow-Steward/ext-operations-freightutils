# Changelog

## 0.1.0

- First release: a step for each of the 40 operations of the FreightUtils API, and everyday shortcuts for a UN number, an HS code, a location code, a container number and an air waybill.
- Each step returns FreightUtils' answer with its source block, data freshness and the request allowance left.
- One connection, with or without a FreightUtils API key.
